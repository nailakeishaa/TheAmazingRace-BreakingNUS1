THE AMAZING RACE: BREAKING NUS - WEBSITE

Open index.html to test locally.

To put it online for free, upload the contents of this folder to any static host such as Netlify Drop, GitHub Pages, or Cloudflare Pages.

How it works:
- Players choose Team W/X/Y/Z.
- Each round has 3 completion buttons.
- Completing all 3 unlocks the riddle.
- Destination answers ignore spaces/capitalization/punctuation.
- Correct answer unlocks the PDF.
- Botanic Gardens uses a different PDF for each team.
- Other rounds use a shared PDF.
- Progress is saved in the browser with localStorage.

Important:
This is intentionally a lightweight friends-game website, not a secure anti-cheat system. PDF files and answers are present in the site's source files.
